📖 各教程介绍

01. 玩转 Markdown

别再傻乎乎地用记事本写笔记了！
Markdown 像极了武林秘籍里的 "轻功"——学起来只需要十分钟，但用好了能让你飞一辈子。只教你最常用的 5% 语法。
学完解锁：优雅地写出一份连程序员看了都想 Star 的笔记。

02. 玩转 VS Code

武装你的"瑞士军刀"
很多人用了好几年 VS Code，还把它当成高级记事本。手把手教你装上那些 "开了挂" 的插件。
学完解锁：一个能让你在任何地方写代码的云端开发环境。

03. Vim 从入门到得体

没有图形界面？那就用键盘征服世界
Vim 的学习曲线陡峭得像悬崖。只讲 10 节必修课，绝不让你背用不到的命令。
学完解锁：在任何一个服务器上都能流畅写代码的底气。

04. 拿捏 Git 与 GitHub

别再把你的代码存桌面了！
Git 专门治"版本混乱"病。GitHub 是程序员的"朋友圈"。
学完解锁：绿油油的 GitHub 贡献墙 + "来，先 Fork 我的项目。"

05. 这才是网络安全（全六季）

省下一万块的培训，免费看完这一套
"相声式"教学法——没有昏昏欲睡的理论，只有让你笑完还能记住的攻击手法。
学完解锁：完整的网络安全知识体系 + 实战项目经验。

06. 这才是 Python 中阶

从零开始，用 Python 武装你的安全工具链
四个子课程：Web 通识 → Flask 开发 → 安全工具（基础）→ 安全工具（进阶）。
学完解锁：把枯燥的渗透工作自动化。

07. Rust: 灰烬之战 进阶

这不是一门语言课，这是一场你必须写 Rust 才能活下来的战争
15 个章节，12 个真实工具，一段从废墟到牺牲的完整叙事。
学完解锁：一门高性能系统语言的完整实战能力。

08. 详解计算机科学丛书 进阶

追随计算机科学的初心，用"大块头"体会编程之道
经典"黑皮书"的伴读指南，告诉你哪些章节必考、哪些可以跳过。
学完解锁：一颗计算机科学的大脑。
